# Eli's TimeShiftKE – store demo

A demo of the Eli's TimeShiftKE WooCommerce store (sample watches only) that runs entirely in the browser with WordPress Playground.

- Store: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/eli-timeshift-demo/main/blueprint.json
- Store admin (products, stock, orders): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/eli-timeshift-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
